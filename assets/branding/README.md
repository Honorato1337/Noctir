# One More Orbit — ícone

A cabeça é uma transcrição vetorial exata dos pixels do sprite original do time em asssets/astronauta/pixil-frame-0.png, região x=8..22, y=2..18. O sprite original não foi alterado. icon.svg é a fonte principal; o primeiro plano adaptativo usa margens maiores para o recorte de Android.

PNG: gerados com Godot em tools/prepare_brand_icons.gd. ICO: conversão dos PNGs de 16, 32, 48, 64, 128 e 256 px para o contêiner ICO. Não há redesenho nem suavização da pixel art.

A janela e o projeto usam icon.svg; o Windows usa one-more-orbit.ico; Android usa launcher-192.png e as três camadas adaptativas. O nome público é One More Orbit. O identificador Android, a assinatura e o caminho de saves Windows foram preservados para manter as instalações e o progresso existentes.
